# AplusCity Desktop Agent
Windows-first local desktop assistant, isolated from the existing web/Companion application.

## Current milestone: local observe mode
- Electron shell with context isolation and sandbox enabled.
- Python HTTP bridge bound only to 127.0.0.1 and protected by a random per-launch bearer token.
- Detects a Windows WeChat installation from common paths and uninstall registry entries.
- Launches installed WeChat desktop executable.
- Enumerates visible top-level Windows windows (title and PID only).
- No chat scraping, message sending, mouse/keyboard injection, screen recording, or Zoom automation is enabled yet.

## Run on Windows 10/11
Requirements: Node.js 20+, Python 3.10+.
```powershell
cd desktop-agent
npm install
npm start
```
The Python bridge uses only the standard library. Ensure `python` is available on PATH.

## Safety
- Service listens only on loopback and requires a random token generated by Electron.
- Do not expose it to LAN or internet.
- WeChat login, QR/MFA and security checks remain user-controlled.
- Current milestone only launches WeChat and lists visible window titles; it does not read chat content or send messages.
- Message sending, recording, deletion, payment and external sharing require explicit confirmation in later milestones.
