# AplusCity Silicon Intelligence — Desktop Agent

Windows-first local digital agent with a unified Brain Core. This project remains isolated from the existing production web application.

## Current milestone: Brain Core V2 desktop runtime

- Electron shell with context isolation, sandboxing, restrictive Content Security Policy and scoped IPC.
- Unified Brain Orchestrator with nine registered specialist roles.
- Configurable OpenAI-compatible model provider.
- Model endpoint, model ID and API key are configured inside the desktop app; API key and settings are stored in the OS-protected encrypted vault.
- Persistent encrypted memory and audit logs, scoped by enterprise and employee identifiers.
- Local memory is excluded from model prompts by default. The user must explicitly opt in before related memory is sent to the configured model endpoint.
- Task planner creates structured, reviewable plans; planning does not execute steps.
- Python HTTP bridge bound only to 127.0.0.1 and protected by a random per-launch bearer token.
- Detects a Windows WeChat installation, launches the app on direct user request, and enumerates visible top-level window titles and PIDs.
- WeChat launch is routed through the Brain tool registry and permission policy.

## Run on Windows 10/11

Requirements: Node.js 22+, Python 3.10+.

```powershell
cd desktop-agent
npm install
npm test
npm start
```

The Python bridge uses only the standard library. Ensure `python` is available on PATH.

The installer is a test artifact, not a signed public release; Windows SmartScreen may show a warning.\n\nTo build locally, run \`npm install\` then \`npm run dist:win\` from this directory.\n\n## First-run setup

1. Open the app and enter an enterprise scope ID and employee scope ID. These are local data-partition labels, not an authentication system.
2. Enter a model ID and a full OpenAI-compatible chat-completions endpoint.
3. Enter the API key. It is encrypted locally and is not returned to the renderer.
4. Save settings, then enter a task and ask the Brain Core to plan it.
5. Opt in to memory sharing only when you want relevant local memories included in the model prompt.

On Windows, Electron safeStorage uses DPAPI. The encrypted vault is protected across Windows user accounts, but not against malicious software already running as the same Windows user. Use a dedicated, secured Windows account for sensitive enterprise data.

## Safety boundaries

- Service listens only on loopback and requires a random token generated by Electron. Do not expose it to LAN or internet.
- Default permission mode is observe.
- WeChat login, QR/MFA and security checks remain user-controlled.
- Current desktop integration only launches WeChat and lists visible window titles; it does not read chat content or send messages.
- No Zoom controls, meeting recording, private chat scraping, mouse/keyboard automation, deletion, payment or external sharing are enabled.
- Sensitive actions require explicit confirmation in the permission layer.
- Enterprise/employee IDs currently isolate local memory only. They do not prove identity or provide enterprise login. Server-side tenant authentication and authorization are future work.
